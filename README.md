### 💰 Expense Tracker App

A simple Expense Tracker application built with HTML, CSS, and JavaScript.  
It allows users to add and delete income/expense values and keeps data saved using LocalStorage.

<img width="1366" height="643" alt="image" src="https://github.com/user-attachments/assets/5389a3e2-99ec-4663-b12f-908cc8a7e476" />

---

#### 🚀 Features

- Add income or expense values
- Delete transactions
- Dynamic list rendering
- LocalStorage support (data persists after refresh)
- Simple and clean UI

---

#### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API
- Bootstrap (for UI layout)

---

#### 📂 Project Structure

- index.html
- /styles/main.css
- /js/main3.js

---

#### ⚙️ How It Works

- User enters a value
- Value is stored in an array
- Array is saved to LocalStorage
- UI is updated using render function
